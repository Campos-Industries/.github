## 📋 Cómo contribuir

¡Las contribuciones son bienvenidas! Si quieres colaborar con alguno de nuestros proyectos:

1. Haz un *fork* del repositorio correspondiente.
2. Crea una rama para tu funcionalidad (`git checkout -b feature/nueva-funcionalidad`).
3. Realiza tus cambios y haz *commit* (`git commit -m 'Añade nueva funcionalidad'`).
4. Sube tu rama (`git push origin feature/nueva-funcionalidad`).
5. Abre un *Pull Request*.

Consulta la guía de contribución de cada repositorio para más detalles específicos.
